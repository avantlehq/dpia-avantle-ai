## Technical Details

### Authentication Flow

**Login:**
```
User → /en/login
  ↓
Enter credentials
  ↓
POST /api/auth/login
  ↓
Validate: username === "toplegal26" && password === "tvarohacek26"
  ↓
Set cookie: dpia_auth = "authenticated" (httpOnly, 7 days)
  ↓
Return 200 { success: true }
  ↓
Client: router.push('/en/dashboard')
```

**Route Protection:**
```
Request → middleware.ts
  ↓
Is public path? (/login, /_next, etc.)
  ↓ YES → Allow
  ↓ NO
Check cookie: dpia_auth === "authenticated"
  ↓ YES → Allow
  ↓ NO → Redirect to /{locale}/login
```

**Logout:**
```
User → Click "Sign out"
  ↓
handleLogout()
  ↓
POST /api/auth/logout
  ↓
Delete cookie: dpia_auth
  ↓
Return 200 { success: true }
  ↓
Client: window.location.href = `/${locale}/login`
```

### Session Management

**Cookie Configuration:**
```typescript
{
  httpOnly: true,              // Not accessible via JavaScript
  secure: process.env.NODE_ENV === 'production',  // HTTPS only in prod
  sameSite: 'lax',            // CSRF protection
  maxAge: 60 * 60 * 24 * 7    // 7 days
}
```

**Middleware Matcher:**
```typescript
{
  matcher: [
    '/((?!_next/static|_next/image|favicon.ico).*)',
  ]
}
```

## Security Considerations

### ⚠️ TEMPORARY SOLUTION - NOT PRODUCTION READY

**Current Implementation Issues:**
1. **Fixed Credentials** - Hardcoded username/password in source code
2. **No Password Hashing** - Credentials in plain text
3. **No Brute Force Protection** - Unlimited login attempts
4. **No Session Encryption** - Only httpOnly cookie protection
5. **No User Management** - Single account only
6. **No Password Reset** - No recovery mechanism
7. **No 2FA** - Single authentication factor
8. **No Rate Limiting** - API endpoints unprotected
9. **No Audit Logging** - No login/logout tracking
10. **No CSRF Protection** - Beyond sameSite: 'lax'

### Production Requirements

**Must implement before production:**
- [ ] Proper user authentication system (Supabase Auth / NextAuth.js)
- [ ] Password hashing (bcrypt, argon2)
- [ ] Rate limiting (express-rate-limit, Vercel edge config)
- [ ] CSRF protection (csrf tokens)
- [ ] Session encryption (iron-session, next-auth)
- [ ] User roles and permissions (RBAC)
- [ ] Audit logging (login attempts, session activity)
- [ ] Password reset flow
- [ ] Email verification
- [ ] 2FA support (TOTP, SMS)
- [ ] Account lockout policy
